Sobre o Projeto

Este projeto é um portfólio desenvolvido com React, criado com o objetivo de apresentar minhas habilidades como desenvolvedor, além de destacar alguns dos principais projetos que desenvolvi ao longo da minha jornada na programação.

A aplicação foi construída com foco em performance, responsividade e experiência do usuário, garantindo uma navegação fluida tanto em dispositivos desktop quanto mobile. O design foi pensado para ser moderno e intuitivo, facilitando o acesso às informações mais importantes, como projetos, tecnologias e formas de contato.

Objetivo

O principal objetivo deste projeto é servir como uma vitrine profissional, onde posso demonstrar na prática meus conhecimentos em desenvolvimento front-end, organização de código e boas práticas.
